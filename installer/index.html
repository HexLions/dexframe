DexFrame installer

Version … · flashes an ESP32 from the browser, over USB. Nothing to install.

1. Which panel do you have?

2. Connect the board and install

  1. Plug the ESP32 into this computer with a USB data cable.
  2. Press the button and pick the serial port of the board.
  3. When it is done, the display shows how to join the DexFrame-Setup Wi-Fi network.

This browser cannot talk to USB serial ports. Use Chrome or Edge on a computer, or flash dexframe-<panel>-factory.bin at address 0x0 with esptool (see the README).

The installer needs to be opened over HTTPS.

Installing erases the board: stored pages, saved card data and Wi-Fi settings. To update a board that already runs DexFrame and keep them, use System → Update firmware in its web page instead.
